## Symptom

Pods Pending with 'Insufficient memory' events; cluster autoscaler does not help.

## Root cause

Container memory request exceeds the largest node size in every pool.

## Fix

Lower the request to fit the node SKU, or add a larger-SKU pool.

## Verification

Pod schedules; no Insufficient memory events.
