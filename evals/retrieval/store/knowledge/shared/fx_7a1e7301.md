## Symptom

Pods stay Pending with '0/6 nodes are available: node(s) had taints that the pod didn't tolerate / didn't match node selector'.

## Root cause

Workload selector targets a pool label that was renamed; the tainted system pool is the only match.

## Fix

Fix the nodeSelector to the current pool label, or add the toleration deliberately.

## Verification

kubectl describe pod shows scheduling onto the intended pool.
