## Symptom

terraform apply fails with 'Error acquiring the state lock'; lock holder is a CI runner that no longer exists.

## Root cause

A killed CI job never released the DynamoDB lock; no TTL on locks.

## Fix

Confirm the run is dead, then terraform force-unlock <LOCK_ID>.

## Verification

plan runs clean; no stale LockID row.
