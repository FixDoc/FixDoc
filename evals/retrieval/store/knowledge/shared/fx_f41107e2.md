## Symptom

After failover, services time out or get read-only errors on writes and never recover alone.

## Root cause

Apps use the old writer's instance endpoint; DNS cached for pod lifetime.

## Fix

Point apps at the cluster writer endpoint; set JVM DNS TTL to 30s; restart pods.

## Verification

Writes succeed within a minute; test failover clean.
