## Symptom

plan/apply fail with ExpiredToken / 'error configuring provider: no valid credential sources'.

## Root cause

AWS SSO session expired mid-run; provider caches nothing.

## Fix

aws sso login for the profile, re-run; in CI, refresh the OIDC role assumption.

## Verification

aws sts get-caller-identity succeeds; plan proceeds.
